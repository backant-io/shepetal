# shepetal

Local dictation for macOS. Hold `fn` to talk, double-tap `fn` for hands-free, and the text lands wherever your cursor is. Speech-to-text runs on your machine with the fastest model it can handle. Your audio and your text never leave your Mac. The only network calls are sign-in, the license check (at launch and once a day, never while you dictate) and checkout, all to shepetal.backant.io, and the one-time speech model download from the 🤫 menu. Signing in brings a sign-in window to the front, so a dictation running at that moment goes to the clipboard (focus moved).

An open-source replacement for Wispr Flow. Status: in design.

## Mac

### Install

From a release (exact click-by-click steps are in each release's notes):

1. Download `Shepetal-<version>.dmg` from the [Mac releases](https://github.com/backant-io/shepetal/releases) and open it.
2. Drag Shepetal into Applications in the window that opens, then open it from Applications. (Opened from the DMG or Downloads instead, it offers once to move itself; it updates itself only from Applications.)
3. Shepetal runs in the menu bar (🤫) with no Dock icon, and a tiny 🤫 sits in the bottom-left corner of the screen. The welcome window shows Microphone, Accessibility and Input Monitoring (and System Audio Recording for meetings, optional) with their live status and an Open button each. Grant the three, sign in with Google if asked, then hold `fn` in the test field. "Start Shepetal when I log in" is ticked; Done applies it.
4. Hold `fn` and talk in any app.

Shepetal sets System Settings › Keyboard › "Press 🌐 key to" to Do Nothing at every launch if it changed (so fn dictates instead of switching the input source), and says so next to 🤫 once. Restore 🌐 key setting in Open shepetal › Settings puts your old value back (until Shepetal starts again).

Updates: release builds check `https://shepetal.backant.io/appcast.xml` once a day with [Sparkle](https://sparkle-project.org) and install a new version in the background, only when Shepetal is idle: never during a dictation, a meeting recording or its transcription, or a re-transcribe, and only 20 minutes after the last fn press (or when you quit). 🤫 › Check for Updates… checks now. Settings › Install updates automatically turns the automatic install off; then a found update shows as "Update to <version>…" in the 🤫 menu. Updates are signed (EdDSA) and Sparkle never installs an older build. A build from source never updates itself, and its menu has no Check for Updates….

Uninstall: Open shepetal › Settings › **Uninstall Shepetal…**, the small grey link at the very bottom (it is not in the 🤫 menu, so it is not clicked by accident). A sheet lists what happens and Cancel is the default: it turns Start at login off, puts back the 🌐 key setting, signs out, moves Shepetal and its speech model (about 1 GB) to the Trash, and quits. Your recordings and history in `~/Library/Application Support/Shepetal` stay unless you tick "Also delete my recordings". Everything goes to the Trash, so you can drag it back. It is disabled during a dictation or a meeting. If the app won't open, run `/Applications/Shepetal.app/Contents/Resources/uninstall.sh` in Terminal instead (`--delete-data` also removes the recordings).

From this checkout: `scripts/make-dmg.sh` builds the DMG, `scripts/make-app.sh --install` builds the app and copies it to `/Applications/Shepetal.app` (it quits a running Shepetal first, opens it again afterwards, and removes an old `~/Applications` copy). A locally built app is not quarantined, so macOS does not block it.

Requirements: macOS 14 or later on Apple Silicon. The speech model (Parakeet v3, about 470 MB) downloads from the 🤫 menu on first run if it is not on the Mac yet. After that nothing goes over the network.

### Build from source

Requirements: Xcode or the Swift 6 toolchain.

```bash
swift build && swift test             # core: fn gestures, model tiers, languages, mic choice and health, dictionary, audio store, history, text rules
scripts/ci/run-checks.sh              # every suite in the repo, as CI runs them (--fast skips Docker and iOS; see docs/ci.md)
scripts/make-app.sh                   # dist/Shepetal.app (menu-bar only), signed (see below)
scripts/make-app.sh --install         # same, then installed to /Applications/Shepetal.app
scripts/make-app.sh --zip             # same, plus dist/Shepetal-<version>-mac.zip for a release
scripts/make-dmg.sh                   # the drag-and-drop installer dist/Shepetal-<version>.dmg (sign-in required, updates on)
scripts/mac/release.sh --dry-run      # the release pipeline without credentials (see "Mac release" below)
scripts/test-uninstall-script.sh      # the fallback uninstaller against stand-ins: 🌐 key, login item, apps, crash watchdog, recordings kept
open dist/Shepetal.app                # add --args --no-permission-prompts to never ask macOS for anything
scripts/check-app.sh                  # launches "Shepetal Check.app" (separate bundle ID, no permissions): menu-bar only, 🤫 bottom-left, alive for 5 min, Quit from the menu
scripts/e2e-mac.sh                    # real pipeline on `say` speech: WER, latency, audio file, app, re-transcribe and cleanup-model checks
                                      # (the first run downloads the 1.3 GB cleanup model into bench/.cache/cleanup; CLEANUP=rules skips it)
sandbox-exec -p '(version 1)(allow default)(deny network*)' scripts/e2e-mac.sh   # same, with the network blocked
```

`scripts/make-app.sh` signs with the first Developer ID Application or Apple Development certificate in your keychain, or with `SIGN_IDENTITY`. With a certificate, macOS keeps the permissions you granted across rebuilds. Without one it signs ad-hoc, and macOS asks for the permissions again after every rebuild.

With a certificate it signs with the hardened runtime and `scripts/mac/Shepetal.entitlements` (the microphone), nested code first (Sparkle's helpers, then each framework, then the app). `UPDATES=1` adds the Sparkle feed and public key to Info.plist; `scripts/make-dmg.sh` sets it, a plain build does not.

### Mac release

`.github/workflows/mac-release.yml` releases an annotated `v<x.y.z>-mac` tag on main in jobs that keep the signing secrets away from repository code (#227):
- **provenance** (no secrets, no repo code): the tag is annotated and its commit is on main;
- **build** (no secrets): `scripts/mac/release.sh --unsigned`: the guard (`scripts/mac/release_guard.py`: tag format, full clone, on main, version and build above the last published Mac release), the Swift tests, and an ad-hoc DMG;
- **sign** (environment `mac-release`, runs no repo script): inline `codesign` of the app inside the DMG with Developer ID and the hardened runtime, nested code first; the designated requirement must equal `scripts/mac/designated-requirement.txt`, or every user would have to grant the permissions again; then `notarytool`, `stapler` and `spctl`;
- **appcast** (environment `mac-release`, runs no repo script): Sparkle 2.10.0's own `generate_appcast`, downloaded and checked against its SHA-256;
- **verify** (no secrets): `scripts/mac/verify-update.swift`, the appcast's EdDSA signature and length against the `SUPublicEDKey` inside the built app;
- **draft** (runs no repo script): a **draft** release with the DMG, its `.sha256` and `appcast.xml`. Nothing is published by CI: try the draft's DMG, write the notes, and click Publish release (a full release, not a pre-release).

Credentials live only in the `mac-release` environment (`MAC_DEVELOPER_ID_P12`, `MAC_DEVELOPER_ID_P12_PASSWORD`, `NOTARY_KEY_P8`, `NOTARY_KEY_ID`, `NOTARY_ISSUER_ID`, `SPARKLE_ED_PRIVATE_KEY`); a missing one fails the run. On the maintainer's Mac, `scripts/mac/release.sh` does the whole release with the login Keychain (the Developer ID identity, the notarytool profile `shepetal-notary`, the Sparkle key from `generate_keys`), and a missing credential makes it a dry run that lists what it skipped. A PR that touches the release path runs `release.sh --dry-run` and then the sign, appcast and verify steps ad-hoc with a throwaway Sparkle key, and keeps the DMG as a workflow artifact. Setup steps: docs/install-and-update.md, "Pavel must provide".

### Use

- The 🤫 menu is short and grouped by intent. At the top, only when needed: Permissions needed… (yellow, opens the Permissions window), the speech recognition download or a line saying it is not ready, Download cleanup model (about 1.3 GB) on an Apple Silicon Mac until it is downloaded, Download dictionary support (about 100 MB) once the dictionary has words and only until it is downloaded, Sign in to start your free trial… when signed out, and Get shepetal for $4.99… from 7 trial days left. Then: Record meeting (Stop meeting recording while one records) and Past meetings, the 8 newest, each opening its transcript (Open Meetings before there are any); Open shepetal; Check for Updates… (Sparkle, release builds only; not there in a build from source); Paste last transcript with its shortcut right-aligned, and Recent (click an entry to copy it); Shortcuts…, Microphone, Languages and Turn off dictation in <the app in front>; Help center (shepetal.backant.io/help, a 404 until the help pages from #84 are deployed) and Send feedback… (an email to founder@backant.io); Quit shepetal (⌘Q). Everything else is in the shepetal window: the account, the speech recognition engine, the cleanup line, your stats, Recent notices, What's new… and the Donate links on Home; mute and pause while dictating, recordings, creator mode, Start at login, Dictionary…, Restore 🌐 key setting and Permissions… in Settings.
- Hold `fn` to talk and release to insert. Double-tap `fn` for hands-free, then tap `fn` once to stop. A press shorter than 0.5 s inserts nothing and shows a hint. Another key pressed in the first second of an fn hold (fn+Delete, fn+arrows) is a shortcut, so that recording is cancelled.
- fn+Space starts hands-free, or locks a hold you already started; press it again to stop (within 0.5 s of the start it cancels). Esc cancels a recording or a transcription and keeps its audio. ⌃⌘V pastes the last text (also Paste last transcript in the 🤫 menu, which shows the shortcut) and ⌃⌘C copies it. Shortcuts… in the menu rebinds each action to up to 3 keys, which must include a modifier, fn or a mouse button (3 to 10). With Accessibility, Shepetal keeps Esc and the shortcut keys from the app you are in.
- A dictation stops by itself after 20 minutes and is inserted, with "1 minute left" shown a minute before. `defaults write io.backant.shepetal maxDictationMinutes -int N` changes the cap.
- 🤫 sits 8 pt in from the bottom-left corner of the main display while Shepetal runs. A red ring means recording, orange hands-free, a pulsing blue ring processing, and yellow an error, with a short message next to it.
- Creator mode (Settings, off by default): while you record or are in hands-free, "Dictating with shepetal" shows next to 🤫, so screen recordings and streams show when you are dictating. It is click-through like 🤫 and goes away when the recording ends.
- Speech-to-text runs locally: Parakeet TDT 0.6B v3 through FluidAudio, from FluidAudio's model cache (`~/Library/Application Support/FluidAudio/Models`). If it is missing, the 🤫 menu offers the download (about 470 MB). The fallback from `docs/models.md` is whisper.cpp: put `whisper-cli` in `~/Library/Application Support/Shepetal/models/whisper.cpp/` and the `ggml-*.bin` model next to it, or set `SHEPETAL_WHISPER_CLI` and `SHEPETAL_WHISPER_MODEL`.
- Cleanup: rules drop fillers and stutters on every dictation. Self-corrections ("actually", "I mean", "no wait"), spoken lists and "new line" then go to a local model: llama.cpp with Qwen3.5 2B (0.8B on 8 GB Macs), downloaded from the 🤫 menu into `~/Library/Application Support/Shepetal/models`. Its text is used only when it is your own words in your order with nothing added, leaving out only list words and a correction's cue plus what the cue takes back. Otherwise the rules' text is used, so a question is typed as you said it, not answered, and a correction said without a cue word stays as said. Dictations over 150 words get the rules only. See [docs/models.md](docs/models.md#cleanup).
- 🤫 > Microphone: Automatic, a device to force, or "Prefer <name>" to move it to the top of your ranking. The choice runs on every dictation: forced device, then the first ranked device that is plugged in, then the system default, never the built-in mic while the lid is closed. A virtual system default (Microsoft Teams Audio, an aggregate, also Krisp or Loopback) is skipped for the built-in mic or another real one; force it to record from it. A dead mic, an unplugged mic, a Bluetooth mic or a very quiet recording each get a short note next to 🤫; the audio is kept either way.
- Voice Isolation: the speech model hears every dictation through Apple's sound-isolation effect (AUSoundIsolation), and the kept WAV stays the raw recording. Shepetal never turns on macOS voice processing or opens the Mic Mode picker, so it never shows up there. `defaults write io.backant.shepetal voiceIsolationMix -float <0-100>` tunes the effect (default 100; see #75 and M-MIC-6).
- 🤫 > Languages: Automatic uses Parakeet, as does any set of its 25 European languages. Other languages use Whisper large-v3-turbo (see `docs/models.md`).
- Settings > Dictionary… opens `dictionary.txt` (owner-only) in your editor: one word or phrase per line to fix its spelling and casing, `spoken => written` for a replacement, `*` to star, `#` for comments. It applies from the next dictation. No entries ship by default. With the default on-device model, the 🤫 menu then offers Download dictionary support (about 100 MB): a small on-device model that listens for your dictionary's words, so they come out spelled and cased as written. It is downloaded only when you choose it, and it works on English dictations only.
- Text goes in through the clipboard and a synthesized Cmd+V. Shepetal checks that an app took the text, then puts your clipboard back about 0.5 s later.
- The text is pasted only if the window you started in is still in focus, and Shepetal never moves focus back. If you clicked into another window, or the paste does not land, the text is left on the clipboard and the note next to 🤫 says to press ⌘V. The text fits the cursor's line: a space before it when needed, a non-breaking space before a following word, and lowercase mid-sentence (names keep their capital), with no period of its own when the sentence goes on after the cursor. Electron apps such as VS Code and Slack are asked for their accessibility tree when the dictation starts, so their fields can be read too. When the field cannot be read, the text goes in as dictated. Over a selection, it takes the selection's case, end punctuation and surrounding spaces.
- When another app has secure input on (a password field, Terminal's Secure Keyboard Entry), a note next to 🤫 says so. Nothing is pasted then: the text is left on the clipboard for ⌘V. A permission turned off while Shepetal runs shows a message and opens the Permissions window, and the yellow ring clears once it is back on.
- Settings has Start at login (the installer turns it on). Shepetal makes no sounds; the 🤫 ring colors show the state.
- Optional: mute other audio or pause media while you dictate (Settings, both off by default). Never during a meeting or a call. Pause presses the play/pause key, so a video you paused just before dictating may start instead.
- "Turn off dictation in <app>" in the 🤫 menu stops `fn` from dictating in the app in front, such as a game, a remote desktop or an app that uses `fn` itself. There, `fn` reaches the app as usual, "Dictation is off in <app>" shows next to 🤫 for 3 s, and nothing records. "Dictation is off in" in the same menu lists those apps; click one to turn dictation back on in it. The list is kept by bundle id in Shepetal's defaults (`dictationOffApps`).
- If shepetal crashes, it opens again by itself within a few seconds: a small watchdog copy of it (`Shepetal --watchdog <pid>`) waits for that. Quit from the 🤫 menu stays quit. After four crashes in a row it stops reopening itself and says so at the next launch.
- Every recording is kept as a 16 kHz mono WAV in `~/Library/Application Support/Shepetal/audio` (folder 0700, files 0600). That includes too-short and failed ones, which are flagged in the history. The history is `history.sqlite` in the same folder. Under Recordings in Settings you can keep everything (the default) or delete recordings after 24 hours. `SHEPETAL_HOME` moves the whole folder.
- Open shepetal in the 🤫 menu, or opening the app again while it runs, shows the Shepetal window. Home has your account first (who is signed in, the trial or license, with Sign in, Buy and Sign out), then the speech recognition engine (standard or alternative), whether `fn` is watched, missing permissions, your stats (words dictated, dictations, words per minute, speaking time, time saved against typing at 40 words per minute, and your top apps by words, for the last 7 days and all time; counted on the Mac from `history.sqlite`, with too-short, cancelled, no-speech and failed recordings left out and archived ones included; `defaults write io.backant.shepetal typingWpm <n>` changes the typing speed), Recent notices (the last 50 hints and errors shown next to 🤫, newest first, so one you missed can be read later; they stay only until Shepetal quits), What's new… (the release notes, newest first; after an update the corner 🤫 says so once), and the Donate links. History has search, copy, play, re-transcribe (with the engine in use or the other installed one) and archive. The app never shows model names; they are in this README, `docs/models.md` and the log. Settings has mute and pause while dictating, recordings retention, the recordings folder, creator mode, Start at login, Dictionary…, Restore 🌐 key setting (when Shepetal changed it), permissions, Install updates automatically (release builds), the version, and at the very bottom the quiet Uninstall Shepetal… link. Each dictation records the app it went to and, in Safari, Chrome, Arc, Edge, Brave, Firefox, Vivaldi or Opera, the page URL. Both stay in `history.sqlite`. Every window follows System Settings › Appearance (Light, Dark, Auto); there is no separate theme setting, and 🤫 and the meeting card stay dark.
- Account: sign in once with Google from the 🤫 menu or Home to start a free 30-day trial (no credit card). Sign-in opens shepetal.backant.io in a macOS sign-in sheet that shares your browser's Google login (OAuth for native apps with PKCE, RFC 8252 and RFC 7636: nothing to type, no code to copy); the sign-in token is kept in the Keychain (service `io.backant.shepetal.account`). After the trial, Shepetal is $4.99 once for a lifetime license with future updates. The top of Home says who is signed in and the days left or "Yours forever" ("Signed in as you@example.com · Trial, 12 days left"), with Sign out. When not signed in or after the trial, Shepetal opens its window on Home once at launch, `fn` only shows a hint next to 🤫 and opens Home (the mic stays off), and Get Shepetal for $4.99 (on Home, and in the 🤫 menu from 7 trial days left) opens checkout. The license is checked at launch and every 24 hours, in the background and never during a dictation. The last answer is cached in `account.json` and holds for 7 days offline. `SHEPETAL_ACCOUNT_URL` points the app at another account service. Release builds require sign-in: `scripts/make-dmg.sh` and `scripts/make-app.sh --zip` set `ShepetalRequiresSignIn` in Info.plist. A build from source does not (`REQUIRE_SIGNIN=1 scripts/make-app.sh` turns it on), so it offers sign-in but dictates without it. `SHEPETAL_REQUIRE_SIGNIN=1` or `0` overrides either when the app starts.
- Meetings: when another app has used the mic or a camera for 5 s (Zoom, Teams, a Slack huddle, Meet in a browser, or any other app), Shepetal asks first. It needs no Screen Recording or Camera access to notice. A small card above 🤫 says "Meeting detected · zoom.us" (the app holding the mic, or "Camera" when only a camera is on) with Record and Not now; it takes the click without taking focus from the app you are in, and goes away after 20 s. Nothing records until you click Record. Not now, or letting the card go, records nothing for that meeting. Settings has "Always record meetings automatically" (off by default) to skip the question. While a meeting records, 🤫 has a red ring the whole time (through dictations too), the menu bar shows 🤫●, and the 🤫 menu has Stop meeting recording; Record meeting records by hand. Your mic and the call audio are kept as `Me.wav` and `Others.wav` in `~/Library/Application Support/Shepetal/meetings` (folder 0700, files 0600), transcribed on the Mac and summarized without an LLM; the Meetings tab in Open shepetal lists them, and 🤫 > Past meetings opens the newest ones.
- Permissions: Microphone, Input Monitoring (to see `fn`) and Accessibility (to paste). The welcome window (first launch, Permissions… and Permissions needed…) shows each one live and opens its System Settings pane.
- Manual checks are listed in [docs/manual-test.md](docs/manual-test.md#mac).
