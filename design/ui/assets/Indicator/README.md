# Indicator

- `shush.svg`: the 🤫 (U+1F92B) from Noto Color Emoji by Google, the unmodified artwork at 128 × 128. Use it for the indicator, the tray and menu bar icon, the app icon and the favicon. Full color; it carries its own inks and never takes `currentColor`.
- Draw the ring around it with the Indicator component (`sh-indicator`); never bake a ring into the file.
