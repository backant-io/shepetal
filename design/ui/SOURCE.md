# Source of this folder

A copy of the "shepetal UI" design system, https://claude.ai/artifact/WJtxYkBnnpZ9uUC6aURdTK (version 1792778497-8a22, 22 October 2026), so code and agents can read it from the repo. The artifact is the source of truth: change it there, then copy it here again.

- `README.md`, `01-platforms.md`, `02-decisions.md`: the brand book for every screen.
- `tokens.json`: every color (Concrete and Night), type style, space, radius, shadow, size, duration and easing.
- `components/<Name>/README.md` and `preview.html`: guidelines and the HTML reference for each component; `components/bundle.css`: every component as CSS (the `--sh-*` custom properties come from `tokens.json`).
- `assets/Indicator/shush.svg`: the Noto 🤫 (Apache 2.0), the same file as `web/public/brand/emoji/emoji_u1f92b.svg`.
