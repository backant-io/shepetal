# Key
The fn key: the brand's one drawn object, a signal-orange keycap whose LED lights while it is held.

- **Provide:** `<button class="sh-key" type="button" aria-pressed="false" aria-label="Hold fn to talk"><span class="sh-key-led"></span>fn</button>`. Set `--key-size` (default 96 px). Set `aria-pressed="true"` while the key is held or hands-free is on; the cap goes down and the LED lights.
- Use it where the brand shows the key itself: the site hero, onboarding ("Press fn"), the shortcut row in Settings, the empty state of Home.
- One per view. It is the view's signal mark, so nothing else on that view is orange.
- The legend is the key's printed name: `fn` on Mac, the chosen key on Windows and Linux (Platforms).
- In running text use the key hint (`Kbd`) instead.
