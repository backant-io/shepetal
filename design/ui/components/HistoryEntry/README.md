# HistoryEntry
One dictation in History: where it went and when in mono, the words as they landed, and quiet tools.

- **Provide:** `<article class="sh-entry"><div class="sh-entry-meta"><span class="sh-label-mono">App</span><span class="sh-label-mono">Time</span></div><div><p class="sh-entry-text">…</p><div class="sh-entry-tools">quiet buttons</div></div></article>`.
- The meta column is the app the text went to and the time, in mono `label`. Add the word count only where it helps.
- The text is shown exactly as it landed, in `app-body`. Never in the serif, never trimmed mid-word; long entries clamp at four lines with "Show all".
- Tools are quiet, icon-and-label buttons: Copy text, Re-transcribe, Delete. They show on hover and focus on desktop, always on touch.
- Use only fictional text in screenshots and previews.
