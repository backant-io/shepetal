# Kbd
A key hint: a small keycap inside running text or a menu, for the keys people press.

- **Provide:** `<kbd class="sh-kbd">fn</kbd>`. One cap per key. On Windows and Linux join keys with `<span class="sh-kbd-plus">+</span>`; on Mac show the symbol and letter in one cap (`⌘V`), no plus.
- The dictation key is the only `sh-kbd--signal`, and only where the sentence is about pressing it now.
- The legend is what is printed on the key: `fn`, `Ctrl`, `Alt`, `⌘`, `⌥`, `Enter`. Never "Function key" or "Cmd".
- In brand and marketing copy, name the key once ("Press one key."). Key instructions belong in product help.
