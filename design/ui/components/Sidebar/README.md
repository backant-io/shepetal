# Sidebar
The app's navigation: five screens on the sunken ground, the current one a raised cap.

- **Provide:** `<nav class="sh-sidebar" aria-label="shepetal">` with `<a class="sh-nav-item" href>` items, each a 16 px Lucide icon and the screen name; `aria-current="page"` on the current one.
- The screens, in this order and spelled as here: Home, History, Meetings, Settings, Dictionary. Nothing else goes in the sidebar.
- 200 px wide (`sh-sidebar`). Below 640 px window width it collapses to icons with the names as tooltips and accessible names.
