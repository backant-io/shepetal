# Menu
The 🤫 menu from the menu bar or tray, and every context menu: a raised panel of rows, the hovered row in ink.

- **Provide:** `<div class="sh-menu" role="menu">` with `<button class="sh-menu-item" role="menuitem">Label<span class="sh-menu-hint">⌘,</span></button>` rows, `<hr class="sh-menu-sep">` between groups and an optional `sh-menu-head` for the current state.
- The 🤫 menu, everywhere: the state in words, then Home, History, Meetings, Settings, then Quit shepetal (Exit shepetal on Windows).
- Hints are mono and follow the platform's key names (Platforms).
- Text fields keep the OS's own context menu.
