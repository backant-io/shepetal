# Segmented
Two to four mutually exclusive options in one sunken well; the chosen one is a raised cap.

- **Provide:** `<fieldset class="sh-seg"><legend class="sr-only">Appearance</legend><label><input type="radio" name="x" checked><span>System</span></label>…</fieldset>`: real radio inputs, one `name`.
- Use for short, parallel choices that change something at once: Appearance, the dictation key's mode. More than four, or long labels: use a menu.
- One or two words per option, sentence case.
